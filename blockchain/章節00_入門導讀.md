## 0.1 什麼是區塊鏈

區塊鏈是一個**由許多互不信任的參與者共同維護的分散式帳本**。帳本記錄「誰擁有什麼、發生過哪些交易」，而「區塊鏈」這個名字來自它的資料結構：交易被打包成一個個**區塊（block）**，每個區塊用密碼學雜湊指向前一個區塊，串成一條**鏈（chain）**。這條鏈被複製到全世界成千上萬個節點上，沒有任何單一方能私自竄改。

```
區塊 N-1              區塊 N                區塊 N+1
┌──────────────┐    ┌──────────────┐    ┌──────────────┐
│ prev_hash: … │◀───│ prev_hash: H(N-1) │◀─│ prev_hash: H(N) │
│ 交易們        │    │ 交易們        │    │ 交易們        │
│ hash = H(N-1)│    │ hash = H(N)   │    │ hash = H(N+1) │
└──────────────┘    └──────────────┘    └──────────────┘

若竄改區塊 N 的任一交易 → H(N) 改變 → 區塊 N+1 的 prev_hash 對不上
→ 之後所有區塊全部失效。這就是「不可竄改」的來源。
```

### 去中心化 vs 中心化

| 面向 | 中心化系統（如銀行） | 區塊鏈（去中心化） |
|------|--------------------|-------------------|
| 帳本由誰保管 | 單一機構 | 全網節點各存一份 |
| 信任對象 | 信任該機構 | 信任程式碼與共識規則 |
| 單點故障 | 有（機構當機/作惡即失效） | 無（部分節點掛掉仍運作） |
| 交易可逆性 | 機構可撤銷/凍結 | 最終化後不可逆 |
| 准入 | 需開戶許可 | 公鏈任何人可參與 |
| 效能 | 高（集中處理） | 較低（人人重複驗證） |

去中心化不是免費的——它用「效能」和「複雜度」換取「不需信任中介」。整本書探討的許多技術（共識、擴展性、跨鏈）本質上都在處理這個取捨。

### 區塊鏈解決的信任問題

區塊鏈真正解決的是**雙重花費（double-spending）**：數位資料可以無限複製，那要如何確保一枚數位貨幣不會被同時花兩次？在沒有中央機構的前提下，答案是——讓全網對「交易發生的順序」達成共識。誰先花的算數、後面的無效。如何在互不信任、且可能有惡意節點的網路裡對順序達成一致，就是**共識機制**（[章節03](章節03_共識機制與安全性.md)）要回答的核心問題。

## 0.2 一筆交易的生命週期

理解區塊鏈最快的方式，是跟著一筆交易走完全程：

```
1. 建立    使用者在錢包中填寫：轉給誰、多少錢、手續費
              ↓
2. 簽章    用私鑰對交易內容簽名，證明「我是發起人且內容未被改」
              ↓
3. 廣播    交易送進 P2P 網路，節點間互相轉發（Gossip）
              ↓
4. Mempool 交易進入各節點的「待打包池」，等待被選中
              ↓
5. 打包    出塊者（礦工/驗證者）挑選交易、組成區塊、執行並更新狀態
              ↓
6. 確認    區塊被加進鏈；後續每多一個區塊，就多一次「確認」
              ↓
7. 最終化  達到足夠確認/最終性後，交易實質不可逆
```

用一段簡化的 Python 表達交易本身的結構（真正的簽章細節見 0.3 與 [章節11](章節11_密碼學基礎.md)）：

```python
from dataclasses import dataclass
import hashlib

@dataclass
class Transaction:
    sender: str        # 發送方地址（由公鑰推導）
    recipient: str     # 接收方地址
    amount: int        # 金額（最小單位）
    nonce: int         # 該帳戶的第幾筆交易，防重放
    fee: int           # 給出塊者的手續費
    signature: bytes = b""

    def hash(self) -> str:
        body = f"{self.sender}{self.recipient}{self.amount}{self.nonce}{self.fee}"
        return hashlib.sha256(body.encode()).hexdigest()

    def is_signed(self) -> bool:
        return self.signature != b""
```

這條路徑上的每一步，都對應本書後面的章節：廣播與 Mempool 屬於 P2P 網路（[章節02](章節02_點對點網路協議與節點通訊.md)）、打包與確認屬於共識（[章節03](章節03_共識機制與安全性.md)）、執行屬於智能合約運行環境（[章節04](章節04_智能合約運行環境.md)）。

## 0.3 雜湊與數位簽章的直覺

整個區塊鏈建立在兩塊密碼學基石上。這裡先建立**直覺**，數學細節與實作留給 [章節11 密碼學基礎](章節11_密碼學基礎.md)。

**雜湊函數（Hash Function）**：把任意長度的資料壓成固定長度的「指紋」。三個關鍵性質：

- **決定性**：同樣輸入永遠得到同樣輸出。
- **抗碰撞**：幾乎不可能找到兩個不同輸入產生同一指紋。
- **雪崩效應**：輸入改一個位元，輸出面目全非。

正是雪崩效應讓「竄改任一區塊就會破壞整條鏈」（見 0.1 圖）。

```python
import hashlib

def h(x: str) -> str:
    return hashlib.sha256(x.encode()).hexdigest()

print(h("hello"))   # 2cf24dba5fb0a30e26e83b2ac5b9e29e1b161e5c1fa7425e73043362938b9824
print(h("hellp"))   # 完全不同 —— 只改了一個字母
```

**數位簽章（Digital Signature）**：用一對「私鑰/公鑰」證明訊息確實由某人發出、且未被竄改。私鑰保密用來簽名，公鑰公開用來驗證。任何人都能驗證簽章，但只有私鑰持有者能產生它。

```python
# 概念示意（真實區塊鏈用橢圓曲線 ECDSA/Schnorr，見章節11）
def sign(private_key, message):        # 只有私鑰持有者能做
    return f"sig({message}|{private_key})"

def verify(public_key, message, signature):  # 任何人都能驗
    return signature == f"sig({message}|{public_key.private_pair})"
```

在區塊鏈裡，你的**地址**由公鑰推導而來，**簽章**證明「這筆從我地址發出的交易確實是我授權的」。私鑰＝資產的唯一控制權，這也是為什麼 [章節07 密鑰管理與錢包](章節07_密鑰管理與錢包實作.md) 如此重要。
