## 內容特色

- **協議實作導向**：以 Python 實作說明底層機制（Merkle 樹、共識、簽章、Rollup、AMM 等），Solidity 範例輔助說明合約與漏洞。
- **比較表與 ASCII 架構圖**：關鍵取捨（信任模型、方案對照）以表格呈現，流程與架構以文字圖示意。
- **🔄 技術更新（2025+）**：各章末附前沿發展追蹤（SSF 單槽最終性、帳戶抽象、EIP-4844 blob、ZK 輕客戶端、後量子密碼學等），掌握主流方向。
- **交叉引用**：章節間以相對連結串連相關主題（如合約 ↔ 合約安全、擴展性 ↔ 現代以太坊、密碼學貫穿全書）。

## 建議學習順序

先讀入門與密碼學打底，再把「基礎 → 安全」與相關主題就近配對：

1. **章節00** → 建立區塊鏈全貌與學習地圖
2. **章節11** → 打底雜湊、橢圓曲線、簽章
3. **章節01 → 02** → 資料結構與 P2P 網路
4. **章節03** → 共識機制、分叉選擇、最終性
5. **章節04** → 智能合約運行環境
6. **章節12** → 智能合約安全（緊接合約基礎）
7. **章節05** → 隱私保護技術
8. **章節06 + 章節14** → 擴展性與現代以太坊技術
9. **章節07** → 密鑰管理與錢包
10. **章節08 + 章節13** → DeFi 與 Token/穩定幣
11. **章節09** → 跨鏈互操作性
12. **章節10** → 治理機制
